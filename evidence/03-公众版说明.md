# 5EPlay App 开屏广告"跳过"按钮——你需要知道的事

## 一句话说明

**5EPlay App 的开屏广告"跳过"按钮，你看到的是一整个按钮，但真正能点中"跳过"的只有中间一小块。你点"跳过"却跳转到广告，不是你没点准——是 App 故意设计成这样的。**

---

## 一、发生了什么？

当你打开 5EPlay App 时，通常经历以下过程：

1. 屏幕显示一个全屏广告，右上角有一个"跳过 5"按钮（数字从 5 倒计时到 1）；
2. 你点击"跳过"想关闭广告；
3. **结果：广告没有关闭，你的手机反而打开了广告页面**（可能是浏览器、应用商店下载页等）；
4. 你返回 App，再次点击"跳过"；
5. **这一次终于正常跳过了。**

很多人遇到这种情况的第一反应是："我是不是没点准？"

**不是你的问题。这是 App 代码里写好的设计。**

---

## 二、为什么说你"没点准"不是你的错？

把跳过按钮想象成这样：

```
你看到的按钮：              实际能跳过的地方：
┌──────────────────┐       ┌──────────────────┐
│                  │       │                  │
│                  │       │                  │
│     跳过 5       │       │    ← 这里 →     │  只有中间这块
│                  │       │                  │  才有用
│                  │       │                  │
└──────────────────┘       └──────────────────┘
    完整的按钮                  约 30%~60% 的区域
```

这个按钮其实由**两层**组成：

- **给你看的一层**（视觉层）：显示完整的"跳过 5"文字，铺满整个按钮。但这一层**点了没有用**——它没有点击功能。
- **真正能点的一层**（点击层）：隐藏在中间，只有整个按钮面积的 30% 到 60%。只有点到这一层，才能真的跳过广告。

**按钮的边缘部分（剩下的 40% 到 70%）——你点上去，点击会直接穿透到下面的广告画面，触发广告跳转。**

更关键的是：**这个 30% 到 60% 的比例，是由 App 的配置参数控制的，可以通过网络更新。** 今天是 50%，明天可能是 30%。你无法知道"安全点击区域"到底有多大、在哪里。

---

## 三、为什么说这是故意的？（四个常识判断）

我们可以用常识来判断这到底是不是一个"写错了的 bug"：

| 如果是 bug（程序写错了）                 | 实际情况                                               |
| ---------------------------------------- | ------------------------------------------------------ |
| 不会专门写代码去识别"用户点了跳过但没用" | **实际情况：代码里有专门的检测逻辑**                   |
| 不会去统计"跳过按钮规避了多少次"         | **实际情况：有专门的数据统计上报**                     |
| 不会在第一次失败后自动"修好"             | **实际情况：代码在第一次点击后自动把按钮扩大到 100%**  |
| 不会把比例做成可配置的参数               | **实际情况：比例由配置参数控制，可以通过网络更新调整** |

**这就像一个自动售货机——你投币进去，它第一次故意不吐货，等你拍一下机器（回到 App）再投币，它才把货吐出来。但机器内部其实记录了"用户第一次投币没拿到货"的次数，作为运营数据。而且，"第一次不吐货"的概率是可以远程调整的。**

---

## 四、为什么大多数用户发现不了？

- 跳过按钮**看起来是完整的**，没有任何提示说只有中间一小块能点；
- **第一次不行就点第二次**——多数人会觉得是自己"没点准"或"手滑了"；
- 第二次一定能成功，用户不会怀疑是 App 的问题；
- 日积月累，这种设计为 App 带来了可观的**额外广告点击量**。

---

## 五、这违反了哪些规定？

最直接的是**《互联网广告管理办法》第十条**（2023 年 5 月 1 日开始施行）：

> "不得设置虚假的关闭标志，不得为关闭广告设置两次或两次以上的操作。"

这条规定明确了两件事：

1. **"关闭"按钮必须是真正的关闭按钮**——本案中，按钮的大部分区域实际上不是"关闭"而是"打开广告"；
2. **关闭广告必须"一键"完成**——本案中，用户通常需要点击两次才能关闭广告。

此外，还涉及：

- **《消费者权益保护法》第八条、第九条**——消费者有权知道服务的真实情况（知情权），有权自主决定是否接受服务（自主选择权）；
- **《广告法》第四十四条**——互联网广告必须"确保一键关闭"。
